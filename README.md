# EPI-em-dia-
**EPI em Dia** é o app corporativo de segurança do trabalho que mantém sua equipe protegida. O RH configura funções, EPIs, jornadas e rotas de fuga (NR-6 e NR-23) uma única vez; o funcionário recebe lembretes push, acompanha validades de EPIs e treinamentos, solicita trocas e consulta a rota de fuga. Multiempresa, em tempo real.
